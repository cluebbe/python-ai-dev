# INSTALL
# -------
# macOS (required BEFORE pip install, PyAudio is compiled against it):
#   brew install portaudio flac
#   On Apple Silicon, `which brew` must show /opt/homebrew/bin/brew.
#   If PyAudio was installed without it, rebuild it after installing:
#   pip install --force-reinstall --no-cache-dir PyAudio
#
# Linux:
#   sudo apt-get install python3-pyaudio portaudio19-dev espeak
#
# Then install all Python packages:
#   pip install -r requirements.txt
#
# Requires Python 3.13. On macOS the AI packages need an Apple Silicon Mac —
# torch no longer publishes Intel (x86_64) Mac builds.
